# Kanagam Tech Academy

Start the learning platform from this folder; no dependency installation is needed:

```sh
npm run dev
```

Open http://localhost:8080 and keep the terminal open.

If port 8080 is busy:

```sh
npm run dev -- --port 8081
```

Then open http://localhost:8081.

If you see a permission error, run the command in your computer's normal terminal. The restricted agent environment cannot open listening sockets.

Source files and feature notes are in [academy/README.md](academy/README.md).

## Redesigned version

A separate edition with improved styling is available in `academy-redesign`:

```sh
npm run dev:redesign
```

Open http://localhost:8081. The original version remains available on port 8080.
